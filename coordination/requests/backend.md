# Backend интеграция мәселелері

Келісім 1.0.0 өзгертілген жоқ. SHA-256: `b8b529d5e9840dcdcda42d91df6359e4584ddea84cdedea17020d7a55dfc8fe9`.

1. **Ортақ бастапқы commit / GitHub:** жеке репозиторийге `I0ve33` аккаунтымен кіру және push құқығы расталды. Backend жеткізілімі `team/backend` тармағына main commit `768f483d17242f8b004d091a299177899936bcb6` негізінде дайындалды; келісім хэші сәйкес. AI және frontend каталогтары өзгертілмейді.
2. **AI:** `ai_engine.pipeline.analyze(payload: dict, emit_progress=None)` async функциясы және `ai_engine/requirements.txt` қажет. Қозғалтқыш жеке процеске импортталады; async callback-ті міндетті түрде `await` етіңіз. Дәлел/санақ/нұсқа тексеруінен өтпеген жауап жарияланбайды. `AnalysisError.code` және `retryable` қауіпсіз тасымалданады; провайдерден келген шикі error message клиентке берілмейді.
3. **Frontend сессиясы:** `fetch(..., {credentials: 'include'})` керек; same-origin әдепкі fetch те жарайды. Local dev кезінде Vite proxy ұсынылады. Талдау ID-сының өзі қолжетімділік кілті емес. Басқа браузер/тазаланған cookie үшін бұрынғы сессия автоматты қалпына келмейді.
4. **Review келісімінің шегі:** PATCH жауабында note/reviewed_at бар, GET results тек review_status қайтарады. Қазіргі код жазбаларды DB мен экспортта сақтайды. Бетті қайта ашқанда note-ты бөлек алу үшін келесі келісім нұсқасына GET review/history маршрутын ұсыну керек; жасырын маршрут қосылмады.
5. **Құжатты жою:** 1.0.0 келісімінде DELETE жоқ. Қате жүктелген/10 файлға толған сессия үшін жаңа analysis жасалады. DELETE керек болса келісім нұсқасын орталықтан өзгертіңіз.
6. **Қорғалған жариялау:** APP_ACCESS_TOKEN қосылғанда Bearer header керек. Қазіргі келісімде 401/403 жазылмағандықтан рұқсатсыз сұрау 404 Error қайтарады. Келесі нұсқада authentication schemes және 401/403-ті ресми құжаттау ұсынылады. Cookie Secure-ді HTTPS артында true етіңіз; бір worker міндетті.
7. **Docker:** `.dockerignore` ортақ инфрақұрылымға қосылды: `.env`, жүктелген құжаттар және виртуалды орталар image build контекстіне түспеу үшін. Frontend/AI/contracts файлдары өзгертілген жоқ. Docker бұл компьютерде жоқ, сондықтан image build басқа ортада тексерілуі керек.
8. **Мәтін шегі:** бір файлға 500 000 таңба / 20 000 үзінді — бэкендтің ресурстық қорғаныс шегі; бұл модель контекстімен өлшенген сапа шегі емес. AI иесі chunking және нақты модель лимитін тексеруі тиіс. Лимитке жеткенде partial/failed және диагностика беріледі.
9. **Кешенді қабылдау:** нақты №8/№9 түпнұсқалары мен API кілттері берілмеген. AI және frontend кодтары ортақ main тармағында бар. AI precision/recall және қазылар сценарийінің толық live өтуі осы жеткізілімде расталмайды.
10. **Summary сілтемелері:** main ішіндегі AI қозғалтқышы summary.reference_ids тізімінде дәлелденген unit_change ID-ларын да береді. Backend оларды mapping/finding ID-ларымен бірге тексереді. JSON келісімі өзгермеді; бұл семантикалық нақтылау ортақ workflow мәтініне енгізілсін. 15 engine бақылау сценарийі backend validator-ынан өтті.
