# AI интеграция сұраулары

API v1.0.0 өзгерісі қажет емес.

1. Backend парсері №9 §5.8 тыйым тақырыбын балалардың `context_span_ids` тізіміне сақтасын. Әйтпесе дұрыс modality шығару сенімділігі төмендейді.
2. №9 §3.9–3.12 сияқты бір Word paragraph ішіндегі бірнеше тармақ бөлінсе, raw text пен locator бақыланушылығы сақталсын. Бөлінбесе толық paragraph жоғалмай берілсін.
3. PDF скан/OCR аяқталмаса және Excel ұяшықтары толық оқылмаса `complete` белгісін бермеңіз.
4. Root `.gitignore` backend иелігінде: `.venv/`, `.env*` (example-ден басқа), runtime data және private input/report каталогтарын қосуды тексеріңіз. Engine өз ішіндегі env файлдарын елемейді.
5. Ортақ release gate: нақты кілтпен бақылау жиынын және ұйымдастырушы құжаттарын жүргізу, содан соң интеграция сценарийін тексеру.
