# Qurylym AI — frontend

Қазақша интерфейс: құжаттардың «дейін/кейін» нұсқаларын салыстыру, тәуекелдерді дәлелмен тексеру және қызметкер шешімін сақтау. React + TypeScript + Vite + Tailwind CSS. Backend пен AI қозғалтқышы бұл каталогқа кірмейді.

## Бірден ашу

Осы компьютерде команда пакетінің түбінен:

```powershell
.\frontend\start.ps1
```

PowerShell скрипттері шектелген жағдайда, қалыпты Node.js орнатылған терминалда төмендегі npm командаларын пайдаланыңыз. Скрипт execution policy өзгертпейді.

- Нақты API режимі: <http://127.0.0.1:5173>
- Жасанды мысал: <http://127.0.0.1:5173/?demo=1>

Негізгі режим — **live**. Демо тек пайдаланушы батырманы басқанда немесе `?demo=1` ашқанда қосылады. API қатесі demo режимін қоспайды. Демо нақты файлдарды талдамайды, AI шақырмайды, түпнұсқа файлдарды бермейді. Демо нәтижесі мен экспорты анық белгіленеді.

## Таза ортадан іске қосу

Node.js **22.12+**, npm қажет. Тәуелділіктердің нұсқалары `package-lock.json` ішінде бекітілген.

```sh
cd frontend
npm ci
npm run dev
```

Dev сервер `127.0.0.1:5173` портында; `/api` сұрауларын `http://127.0.0.1:8000` backend-іне бағыттайды. Басқа backend керек болса `.env.example` → `.env.local` көшіріп, `VITE_API_BASE_URL=https://your-api-host` орнатыңыз және Vite-ті қайта іске қосыңыз. API URL-іне `/api` енгізу де қолдау табады. Бөлек origin кезінде backend credentials бар CORS сұрауларын рұқсат етуі керек.

Браузерге ешқандай OpenAI/NVIDIA кілтін бермеңіз. `VITE_*` айнымалылары ашық frontend жинағына енеді. Барлық AI сұрауы backend арқылы жүреді.

## Production

```sh
cd frontend
npm ci
npm run build
```

Нәтиже — `frontend/dist/`. Біріктіруші оны backend серверінен ұсынады; браузердің `/api/*` сұрауларын FastAPI өңдейді. `npm run preview` тек жинақты жергілікті тексеруге арналған және dev API proxy қолданбайды. Ортақ Docker/README/backend файлдары frontend жұмысында өзгертілмеген.

## Іске асырылған сценарийлер

- DOCX/PDF/XLSX: бірнеше файл таңдау немесе drag-and-drop; бір файлға 20 МБ, талдауға 10 файл; формат пен бос файлды тексеру. API-ға әр файл жеке және кезекпен жіберіледі. Сервер файлдың мазмұнын өзі қауіпсіз тексеруі керек.
- Топ ауыстыру; құжат атауы, түрі, редакциясы, SHA-256, өңдеу күйі және диагностикасы. Метадеректі өзгерту API 1.0.0 келісімінде жоқ болғандықтан, тек алынған дерек көрсетіледі.
- `uploaded/parsing/extracting/matching/verifying/completed/partial/failed` күйлері. Polling, ұзақ өңдеу хабарламасы, қолмен қайта жаңарту, сессияны бет жаңарғанда қалпына келтіру.
- Бір run-ның желілік retry-ы және бет жаңартылғаннан кейінгі retry сол `Idempotency-Key` қолданады. Жүктеу POST-ы автоматты қайталанбайды. 409 кезінде ағымдағы күй қайта оқылады.
- Тәуекел сүзгілері: түрі, өзгерісі, бөлімше, қызметкер шешімі және мәтін іздеу.
- Функциялардың бұрынғы/кейінгі жауаптысы, міндеті, шеңбері, шарттары, жиілігі, қамтуы және бірнеше өзгеріс белгісі. Бос `after_function_ids` үшін кейінгі дәйексөз жасалмайды.
- Құрылымның екі бағанды картасы, бағыныштылығы, өзгерісі және дәлел негізі. Функциялық болжам ресми құжат дәлелінен ажыратылады.
- SourceEvidence: өзгермеген түпнұсқа мәтін, контекст, DOCX тармағы, PDF беті немесе XLSX парағы/ұяшығы; түпнұсқа жүктеу.
- Қолдайтын/қарсы дәлелдер, іздеу ауқымы, ұсынылатын әрекет; confirmed/rejected/needs_information/unreviewed және түсініктемені сақтау.
- Қорытындының сілтемелерін ашу, API арқылы HTML/CSV жүктеу. Жауап сәтті болғаннан кейін ғана файл беріледі.
- Мобильді орналасу, пернетақтамен басқарылатын tabs, modal focus/escape, негізгі мазмұнға өту сілтемесі, қозғалысты азайту баптауы, мәтін және түс арқылы мәртебелер.

Санақтар API-дан алынады. Қамту модель дәлдігі ретінде көрсетілмейді. Бастапқы құжат мәтіні React арқылы мәтін ретінде шығарылады; `dangerouslySetInnerHTML` қолданылмайды.

## API келісімі

- Нұсқа: **1.0.0**.
- SHA-256: `b8b529d5e9840dcdcda42d91df6359e4584ddea84cdedea17020d7a55dfc8fe9`.
- Клиент: `src/api/client.ts`; барлық желілік сұрау осы модульде.
- Типтер және runtime схемалар: `src/api/types.ts`, `src/api/schemas.json`.
- Төрт бастапқы мысал: `src/demo/*.example.json` — ортақ мысалдардың өзгермеген көшірмелері.
- `npm run contract:check` ортақ `../contracts/` каталогымен хэш пен generated файлдарды салыстырады.
- Келісім орталықтан жаңартылса ғана `npm run contract:generate` орындаңыз. Frontend келісімді өз бетінше өзгертпейді.

AJV әр JSON жауабын схема бойынша тексереді. Басқа revision-ның нәтижесі немесе сәйкес емес source/review ID қабылданбайды. Сессия ID-сы мен run кілті `sessionStorage` ішінде; нақты құжаттар және нақты қызметкер түсініктемесі браузер storage-ына көшірілмейді. Demo түсініктемесі ғана сол demo сессиясына сақталады.

## Код құрылымы

```text
src/api/          HTTP клиенті, схема валидациясы, generated типтер
src/hooks/        сессия, upload, polling, retry, review күйі
src/components/   жүктеу, прогресс, нәтижелер, дәлел панелі, есеп
src/demo/         анық белгіленген typed demo provider және мысалдар
src/lib/          домен атаулары, файл шектеулері, көмекші функциялар
tests/            Playwright + axe браузер сценарийлері
scripts/          API келісімінен генерациялау және тексеру
```

## Тексеру

```sh
npm run typecheck
npm test
npm run build
npm run contract:check
npx playwright install chromium
npm run test:e2e
npm audit
```

Егер Chromium жүктелмесе, орнатылған Google Chrome-мен тексеруге болады:

```powershell
$env:PLAYWRIGHT_CHANNEL = 'chrome'
npm run test:e2e
```

Браузер тесттері production жинақты `127.0.0.1:4173` портында ашады. Олар HTTP келісімін route interception арқылы имитациялайды; **нақты backend/AI интеграциясы болып саналмайды**. HTML есебі: `playwright-report/index.html`. Нақты орындалған командалар, тест санақтары және шектеулер `../coordination/frontend.md` ішінде.

Кодты форматтау: `npm run format`; форматты тексеру: `npm run format:check`.

## Біріктіру және қалған шектеулер

Frontend-ті команданың ортақ репозиторийіне `frontend/` ретінде, дайындық есептерін `coordination/` ішіне енгізіңіз. `node_modules`, `.tools`, `.env.local`, `dist`, test-results және архивті commit-ке қоспаңыз.

API 1.0.0-де ескі review түсініктемесін оқитын endpoint жоқ: refresh-тен кейін шешім мәртебесі қалпына келеді, бұрынғы түсініктеме есептен оқылады. Форманы қайта сақтау түсініктемені алмастыратыны UI-да жазылған. Метадерек PATCH тек топты ауыстырады; edition/title редакторын қоспадық. Осы екі келісім шектеуі `coordination/requests/frontend.md` ішінде тіркелген.

Толық қабылдау үшін команданың backend + AI бөлігімен нақты DOCX/PDF/XLSX → AI → дәлел → review → экспорт сценарийін іске қосу керек. Модель сапасы, OCR, серверлік авторизация және нақты файл парсерлері frontend тестімен расталмайды.
