# Qurylym AI: қорғау және соңғы тапсыру

## Платформаға арналған қысқаша сипаттама

Qurylym AI — ұйымды қайта ұйымдастыру кезінде бөлімшелер мен функциялардың өзгерісін салыстыратын ЖИ агентінің прототипі. Қызметкер «дейінгі» және «кейінгі» DOCX, мәтіндік PDF немесе XLSX құжаттарын жүктейді. Жүйе бөлімше өзгерістерін, міндеттің сақталуын немесе ауысуын, ықтимал жоғалуын, қайталануын және берілген тәуелсіздік талаптарына қайшы келетін рөлдерді талдайды.

Әр маңызды қорытындыдан бастапқы құжаттың тармағына, үзіндісіне және түпнұсқасына өтуге болады. Дәйексөздер кодпен тексеріледі, мағыналық ұсыныстар бөлек AI сұрауымен қайта қаралады. Қамту жеткіліксіз болса, жүйе белгісіздікті көрсетеді. Қызметкер қорытындыны растайды, қабылдамайды немесе қосымша ақпарат сұрайды; шешімі мен түсініктемесі сақталады. HTML және CSV есептері жүктеледі.

Шешім React/TypeScript интерфейсінен, FastAPI/SQLite серверінен және OpenAI Responses қолданатын Python AI модулінен тұрады. README-де орнату командалары, архитектура, қайта тексерілетін жасанды құжаттар және нақты тест нәтижелері берілген. AI тұжырымдары ұсынымдық сипатта және қызметкер тексеруін талап етеді.

## Міндетті талаптардың дәлелі

| Талап | Өнімде көрсету | Қайта тексеру |
|---|---|---|
| Сақталған, қайта ұйымдастырылған және құрылған бөлімшелер | Құрылым өзгерістері | `backend/tests/fixtures/judge/`: §1.1–1.2 |
| Функцияларды салыстыру және ықтимал жоғалу | Функциялар кестесі, қамту және жоғалу | Бұрынғы §2.2: апталық көшірме тексеруі |
| Қайталану және ықтимал мүдделер қақтығысы | Тәуекел карталары, екі міндеттің дәлелі, берілген шектеу | Judge кейінгі §2.2/§4.1; `evaluation/fixtures/conflict.input.json` және `executor_controller.input.json` |
| Дереккөзге дейінгі байланыс | Дәлел панелі, тармақ/бет/ұяшық, түпнұсқаны жүктеу | HTTP smoke барлық қолданылған source ID-ды ашады |
| Түсінікті қорытынды | Қысқа қорытынды, қамту санақтары, ұсыныстар, review, экспорт | Нақты браузер сценарийі және HTML/CSV |

## Үш минуттық көрсету

1. **0:00–0:25.** «Қайта ұйымдастыру кезінде қызметкерге әр міндеттің жаңа жауаптысын және оны растайтын тармақты табу керек. Біз осы салыстыруды бір жұмыс жолына жинадық».
2. **0:25–0:50.** `backend/tests/fixtures/judge/` ішіндегі before/after DOCX жұбын жүктеңіз. Файлдардың жасанды екенін айтыңыз. Талдау іске қосылғанын, нақты кезеңдер мен диагностика көрсетілетінін көрсетіңіз.
3. **0:50–1:25.** Құжат айналымы → Ақпаратты басқару қайта аталуын көрсетіңіз. Тіркеу міндеті сақталғанын, ал резервтік көшірмені тексеру міндеті кейінгі жиында табылмағанын ашыңыз.
4. **1:25–2:05.** Мұрағаттау қайталануын ашыңыз: кейінгі §2.2 және §4.1. Екі дереккөзді қарап, түпнұсқаны жүктеңіз. «Бірдей тақырып өздігінен қайталану емес; субъект, әрекет, объект және міндет ауқымы салыстырылады» деп түсіндіріңіз.
5. **2:05–2:35.** Қызметкер шешімін және түсініктемесін сақтаңыз. HTML/CSV есепті жүктеңіз. AI қорытындысы мен адамның шешімі бөлек екенін көрсетіңіз.
6. **2:35–3:00.** README, нақты тест есебі және шектеулерді ашыңыз. Мүдделер қақтығысы үшін құжатпен берілген тәуелсіздік/тыйым талабы қажет екенін айтыңыз. Орындалмаған тексеруді өткен деп айтпаңыз.

Уақытты үнемдеу үшін алдын ала өзіңіз талдаған нәтижені ашып қойып, жүктеу сценарийін бөлек көрсетуге болады. Қай нәтиже алдын ала дайындалғанын ашық айтыңыз. Интерфейстегі жасанды demo режимін нақты AI нәтижесімен шатастырмаңыз.

## Соңғы тапсыру

1. GitHub `main` тармағындағы соңғы commit пен Render build commit-інің сәйкес екенін тексеріңіз.
2. Render-де **Live** болғаннан кейін `/api/health`, жаңа браузердегі кіру, бақылау құжаттары, нәтиже және экспортты тексеріңіз.
3. Нақты HTTPS URL-ді түпкі README-ге және платформадағы сипаттамаға енгізіңіз. Кіру коды орнатылса, қазыларға сол кодты беріңіз; API кілтін бермеңіз.
4. Хакатон платформасында осы кейсті таңдап, **«Шешімді тапсыру»** батырмасын басыңыз. Жоба атауы: **Qurylym AI**. Репозиторий, README және жұмыс істейтін URL көрсетілсін.
5. Тапсыру қабылданған мәртебені сақтап алыңыз. GitHub push өздігінен платформалық тапсыру болып саналмайды.

Render Free — уақытша демо: ұйқыдан оянуға уақыт кетуі мүмкін, қайта іске қосылғанда жергілікті база жоғалуы мүмкін. Маңызды нәтижені экспорттап алыңыз. Толық баптау: [RELEASE_PLAN.md](RELEASE_PLAN.md); нақты орындалған сынақтар: [VERIFICATION.md](VERIFICATION.md).
