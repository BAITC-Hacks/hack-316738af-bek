## Нақты модель сапасы

OpenAI `gpt-4.1`, NVIDIA өшірулі. 15 жағдайдың күтілетін жауабы тек бағалаушыда, модельге жіберілмейді.

| Сынақ | Нәтиже |
|---|---|
| `qurylym-1.0.1` толық жиын | 15/15 өтті; 87 API шақыруы; 169.5 с |
| `qurylym-1.0.2`, source ID қысқарту | 14/15 өтті; дәйексөз қатесі бір baseline chunk-ті тоқтатты |
| `qurylym-1.0.2`, дәйексөзді бір рет қайта сұрау | 11/15 өтті; 86 шақыру; 163.0 с |
| Үш қате жағдайды диагностикалық қайта іске қосу | duplicate, persistent, prohibition үшеуі де өтті; код арасында өзгермеген |

Алдыңғы қайталаулар **модель тұрақсыздығын көрсетеді**. 1.0.2 толық жиынындағы ақаулар: екі қайталану өткізіліп кетті, тыйым жағдайында `RESULT_INVARIANT_FAILED`, қайта атауда `GROUNDING_REJECTED`. Кейінгі жеке сәтті қайта іске қосу бұрынғы сәтсіз сынақты өшірмейді. Сол 1.0.2 жиынының risk precision=1.0, recall=0.3333; шағын жиындағы көрсеткіш, жалпы өнім дәлдігі емес.

Кейінгі түзетулер: қолдайтын модельдерге `temperature=0`, қысқа wire ID-лар, бірдей міндеттің теріс risk шешімін қайта тексеру және нақты иерархияны ажырату. Төмен температура толық детерминизм кепілі емес.

| Кейінгі толық сынақ | Нәтиже |
|---|---|
| `qurylym-1.0.3` | 14/15; ата-ана басқаруы мен баланың орындауын қате қайталану деп санады |
| `qurylym-1.0.4` | 15/15; 87 API шақыруы; 148.2 с; risk precision/recall 1.0/1.0 |
| `qurylym-1.0.6` | 15/15; 87 API шақыруы; 143.3 с; risk precision/recall 1.0/1.0 |

Қазақша DOCX бақылауындағы тарихи атауды кейінгі құрылымға бөлек entity ретінде қосу түзетілді. Бұрын ол `GROUNDING_REJECTED` және белгісіз қамту тудырған; түзетуден кейін HTTP semantic assertions өтті. `qurylym-1.0.7` жалпы «ұйым» сөзін негізсіз жеке атауға айналдырмауды нақтылайды; осы нұсқадағы нақты judge browser қабылдауы өтті.

Жеке нәтижелер жергілікті `evaluation/local_reports/` ішінде сақталады. Қайталату командасы түпкі README-де. API usage нақты есептеледі; долларлық шығын немесе қалған кредит ойдан көрсетілмейді.

## Ұйымдастырушының құжаттары

№8 және №9 түпнұсқа DOCX әрқайсысынан backend парсері 496 үзінді шығарды. №8-де бос тармақ бар: `partial`; №9 парсингі `complete`. Жалпы мәтін көлемі 167 255 таңба.

Алғашқы толық нақты AI талдауы 900 секундта `ANALYSIS_TIMEOUT` күйімен аяқталды. 96 OpenAI шақыруы, 1 177 028 input және 213 738 output tokens есептелді; осы әрекетте кэш қолданылмады. **Толық құжаттық қабылдау өтпеді.** Түпнұсқалар, API жауаптары және құпия материал Git-ке кірмейді. Семантикалық бақылау тармақтары: [ORGANIZER_REGRESSION.md](../evaluation/ORGANIZER_REGRESSION.md).

## Түзетілген ақаулар

- Лауазым ID-сы бөлімше өрісіне түскенде, құжатпен расталған сол субъект entity түріне сай өріске ауыстырылады; жаңа жауапты ойдан қосылмайды. Регрессия тесті бар.
- Ұзын source ID-ларды модель сұрауында қысқа белгілерге ауыстыру; жауапта бастапқы ID дәл қалпына келеді. Entity атаулары мен мәтін өзгермейді.
- Қате дәйексөзге бір рет регенерация; екінші қате жауап та қабылданбайды.
- Бөлек тыйым бар болғандықтан нақты тағайындалған міндетті өшірмеу; белгісіз жауаптыға null сақтау жөніндегі нұсқаулар нақтыланды.
- Browser access: signed HttpOnly cookie, қате кіру шегі, сессия оқшаулауы. Login формасының `Origin: null` ақауы `/access` үшін `Referrer-Policy: same-origin` арқылы түзетілді.
- Белгісіз жауаптысы бар тәуекелді құрастырудағы `None`/string сұрыптау қатесі түзетілді; регрессия тесті бар.
- Үлкен салыстырулар шектеулі параллель өңделеді. Әр нұсқада 200 risk кандидаты таңдалады; шектелген іздеу `partial` деп белгіленеді, орындалмаған тексеру табысты саналмайды.
- Сервер `PORT` айнымалысын және бір worker режимін қолдайды. Render Blueprint дайын.

## Әлі орындалмаған қабылдау

- Docker build: осы компьютерде Docker орнатылмаған.
- Render: сервис/HTTPS URL құрылмаған; бұл конфигурация әзірге жарияланбаған.
- GitHub Actions: алдыңғы workflow аккаунт billing lock себебінен орындалмады. Жергілікті тесттерді cloud CI өтті деп көрсетпейміз.
- Көлемді бастапқы құжаттарды толық семантикалық қабылдау және нақты сервердің жады/уақыт шегі.
- NVIDIA-мен нақты live шақыру, Chrome/Firefox/Safari үйлесімділігі.

Келесі қабылдау және жариялау реті: [RELEASE_PLAN.md](RELEASE_PLAN.md).
