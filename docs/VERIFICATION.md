## Нақты модельді бағалау

- Модель: `gpt-4.1`, prompt: `qurylym-1.0.7`, NVIDIA өшірулі.
- Соңғы толық жиын: **15 жағдайдың 15-і өтті**, 87 API шақыруы, 140.344 секунд.
- Синтетикалық risk precision/recall: **1.0 / 1.0**. Бұл бүкіл өнімнің немесе басқа құжаттардың 100% дәлдігі емес.
- Жағдайлар: өзгеріссіз, жоғалу, ауысу, мерзім өзгеруі, бөліну, бірігу, қайталану, бұрыннан бар тәуекел, қақтығыс, орындаушы/бақылаушы, әртүрлі ауқым, тыйым, белгісіз жауапты, иерархия, қайта атау.
- Күтілетін белгілер бағалаушыда ғана қолданылады; модельге жіберілмейді.
- Нақты қазақша HTTP бақылауы: 7 функция, 2 finding, 11 OpenAI шақыруы; қайта атау/жоғалу/қайталану және дұрыс source сілтемелері тексерілді. Бұл сценарий VS Code-тағы біріктірілген жобада да өтті.

Модельдің алдыңғы қайталауларында өткізіп алу және дәлелдің қабылданбауы кездесті. Соңғы браузерлік қолмен қайталауда да `partial` нәтиже байқалды. Сондықтан қызметкер тексеруі, диагностика және белгісіз қамту интерфейсте сақталады.

## Көлемді құжаттардағы шекара

Ұйымдастырушының №8/№9 DOCX жұбынан әрқайсысы 496 үзінді оқылды; жалпы мәтін — 167 255 таңба. Соңғы толық талдау 900.11 секундта уақыт шегіне жетті: 96 API әрекеті, 684 775 input және 297 127 output token. Бұл әрекетте кэш қолданылмады. 315 функция шығарылғанымен, толық нәтиже қабылдауы аяқталмады. Үлкен құжаттарды толық әрі жылдам өңдеу — ағымдағы прототиптің шектеуі.

## Қайталату

Орнату және модель бағалау командалары түпкі [README](../README.md) ішінде. Нақты браузер сценарийі:

```powershell
backend\.venv\Scripts\python -m backend.scripts.live_browser --url http://127.0.0.1:8000 --channel msedge --fixture-set judge
```

Нәтижелер жергілікті `evaluation/local_reports/` және `backend/test-results/` ішінде жасалады. Құпия файлдар мен API жауаптары Git-ке қосылмайды.

## Орындалмаған тексерулер

- Осы компьютерде Docker жоқ: жергілікті контейнерлік build орындалмаған.
- GitHub Actions соңғы run-да орындалған қадамдарсыз failure көрсетті; жергілікті тесттер cloud CI нәтижесі болып ұсынылмайды.
- NVIDIA-мен нақты интеграциялық сынақ және Firefox/Safari үйлесімділігі тексерілмеген.
- Render қабылдауы жариялау аяқталғаннан кейін бөлек расталады.
